# Modelo

Esta carpeta contiene los datos y las reglas de negocio del proyecto Apoyo Educativo.

## Entidades

### Beneficiario
Atributos:
- Nombre
- Fecha de nacimiento
- Encargado

Regla de negocio:
- La fecha de nacimiento no puede ser futura.

### Encargado
Atributos:
- Nombre
- Teléfono
- Parentesco

Regla de negocio:
- El teléfono debe tener 8 dígitos.
