# Vista

Esta carpeta contiene las pantallas que permiten al usuario interactuar con el proyecto Apoyo Educativo.

## Pantallas principales

### Formulario de registro de beneficiario
Muestra los campos necesarios para registrar los datos de un beneficiario, como nombre, fecha de nacimiento y encargado.

### Listado de beneficiarios registrados
Muestra los beneficiarios que han sido registrados en el sistema.

### Pantalla de inicio de sesión
Muestra los campos necesarios para que el usuario ingrese sus datos de acceso al sistema.
